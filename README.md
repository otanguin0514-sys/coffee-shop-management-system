# Brew Haven Coffee Shop Management System

A modern coffee shop management dashboard designed for daily operations, sales tracking, menu management, inventory control, and staff monitoring.

## Features
- Sales dashboard with revenue and order summaries
- Coffee menu with category filtering
- Live order panel with total calculation and tax
- Inventory health overview
- Staff schedule and status cards
- Responsive design for desktop and mobile

## Run locally
Open `index.html` in a browser.

## Technologies
- HTML
- CSS
- JavaScript
